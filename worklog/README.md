# Worklog

One Markdown file per work session/task. Use `YYYY-MM-DD-NN-short-description.md` with the Asia/Bangkok date and next available daily sequence. Retrospective dates describe the original work; each such file also states when it was reconstructed and its evidence. Sequence numbers organize entries and do not assert exact historical session times.

Read `../AGENTS.md` for the required workflow. Do not append new entries to `../WORKLOG.md`.

## Entry template

```markdown
# Task title

- Work date: YYYY-MM-DD (Asia/Bangkok)
- Type: current session / retrospective
- Starting commit / evidence:

## Request
Objective and scope.

## Work performed
Changes, decisions and affected files.

## Verification
Commands/checks actually run and their results. Identify historical reports separately.

## Remaining work / limitations
Unverified behavior, blockers or next steps; use None when appropriate.
```
